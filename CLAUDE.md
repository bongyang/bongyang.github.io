# Handover for AI sessions

Personal academic site for Dr Yang Bong. Image-led home page plus one page per
section (Nov 2026 restructure), plain HTML/CSS/vanilla JS, no build step, hosted on GitHub Pages (user site `bongyang.github.io`).

## Hard rules

- **Never invent publications, roles, numbers, dates or claims.** The CV and
  `publications.bib` are the source of truth. If something is missing, add a
  marked TODO to the `todos` array in `content.json` and tell the user.
- **Never publish the phone number.** Contact is email only.
- Use DOIs exactly as given in the `.bib`.
- Do not push to `main` or change GitHub Pages settings unless asked. Review
  work goes on the `preview` branch; the owner merges.
- First person, warm and confident, British English, but keep "I" sparing:
  vary sentence openings so it does not read as self-promoting. "Indigenous" is
  capitalised.

## Structure

- Pages: `index.html` (home), `research.html`, `publications.html`,
  `impact.html`, `teaching.html`, `citizenship.html` (content id `service`).
  All are identical shells generated by `python3 scripts/make_pages.py` from
  `scripts/page.template.html`; only `<head>` text and `<body data-page>`
  differ. Do not hand-edit the page HTML; rerun the script.
- `content.json` — all visible text. `todos` is never rendered.
  Inline links use `[label](https://url)` (see `rich()` in `main.js`).
  `nav[]` has `href` per page (Home is `./`; Contact is `#contact`, on every page).
  `pages.<id>` holds each page's teaser and photo (home cards + page hero).
  `home` holds the cover photo, tagline, statement and featured project.
- `publications.bib` → `python3 scripts/bib_to_json.py` → `publications.json`.
  Never hand-edit the JSON. Commit both. Groups: `article` → journal,
  `inproceedings` → conference, everything else → report.
- `assets/js/main.js` — fetches both JSON files and renders `#page` according
  to `data-page`: `renderHome()` (full-bleed cover with crossfading photos
  from `home.heroSlides` (5.5 s, pause button, off for reduced motion;
  `coverSlides()`), name, intro, image
  cards, dark featured-project band with meta row, photo mosaic from
  `gallery`, three newest publications) or `renderPage()` (page hero with photo, section body
  from `body.<id>()`, "Next" link to the following page). Contact band and
  footer render on every page. Old one-page links (`/#research`) redirect to
  the new pages. No dependencies. Escape everything with `esc()`.
- `assets/css/style.css` — mobile-first; breakpoints at 48rem and 64rem.
  Pill nav (swipeable below 64rem, where seven pills don't fit); on home the masthead floats over the cover (`.is-over`) until it
  scrolls past.
- Research themes: optional `current` list (rendered under the label
  `research.currentLabel`, inline links allowed) above the related
  publications. Themes link to publications by BibTeX key
  (`research.themes[].publications`), rendered as `publications.html#pub-<key>`.
- Photos: `pic()` in `main.js` takes `{src, widths?, width, height, alt,
  position}`; with `widths` files are `NAME-800/NAME-1600` (.webp + .jpg),
  without, `NAME.webp/.jpg`. `position` is the object-position for crops.
- Photo mosaic (`gallery` in content.json) on the home page, rendered by
  `galleryHtml()`: `size` "lg" (2x2) or "wide" (2x1), else 1x1; the places
  strip is `gallery.places` (owner's list of countries), falling back to each
  item's `place`. Event photos live in
  `assets/img/banner/` as `NAME-800/-1600/-2400` (only widths up to the
  original's size), field photos in `assets/img/impact/`. All made by
  `scripts/enhance_photos.py` (use `--light` for good originals), which must
  never crop or retouch. Optional `positionMobile` sets the crop on phones.
  Captions must only state what is known; flag guesses in `todos`.
- Icons are inline SVG in `main.js`, keyed by `links[].id`.
- Impact map: one fixed view of Southeast Asia (no zooming, by the owner's
  choice). `assets/img/map-world.svg` is generated by `scripts/make_map.mjs`
  (Natural Earth via world-atlas; Borneo highlighted, Malaysian Borneo darker)
  and loaded inline by `initMap()` in `main.js`, which crops it to
  `impact.map.bounds` (`boundsMobile` on phones) with the SVG viewBox.
  Markers and `labels` are HTML placed with the same equirectangular
  projection (`impact.map.projection`; keep script and content in sync). Label
  `kind`: country (default), state, small (both hidden on phones), island,
  water. Places are town-level; timeline entries link to places via `place` =
  place `id`.
- Page heroes: title left, photo right; `pages.<id>.heroImage: false` gives a
  text-only hero (Publications, where `image` is used only for the home card).
  Title size is tied to the column width so long words never run under the
  photo.
- Publications: `publications.photoBreaks` puts photos after a group (`after`
  = group id). `photoBreak()`: one photo = wide banner; several = rotating
  banner (`rotatorHtml()` / `initRotators()`: 6 s, dots, pause, holds on
  hover/focus, still for reduced motion). Owner prefers rotating banners to
  showing many photos at once.
- Citizenship: `service.feature` (ASEFInnoLab7: text + rotating banner), then `service.groups` in order: "Conferences and networks"
  (its `photos` shown as a rotating banner), then "Peer review" (owner wants
  conferences listed before reviewing).
- Publications: theme filter (`data-themes` from `research.themes`), Cite
  panel (`<details>`, APA built by `apa()`, raw BibTeX from the `bibtex`
  field), schema.org JSON-LD injected by `structuredData()`.
- Impact items: first is the dark lead (Long Semadoh, followed by the project
  block); `wide: true` makes a full-width section (SARI report, facts from the
  IRC report page). Page intro: `impact.intro`.
- Facts in `impact.project` come from the Horizon CDT page
  (https://cdt.horizon.ac.uk/yang-bong-large-impact-grant/); do not embellish.
- Each page preloads `content.json`, `publications.json` and its hero photo
  (set by `make_pages.py` from content.json).
- Before render, `html:not(.is-ready)` hides `#page`, nav, contact and footer
  so nothing shifts. Keep that if you change the loading logic.

## Design tokens (`:root` in style.css)

- Paper `#FBF9F4`, deep paper `#F3F0E7`, ink `#1B2420`, muted `#56615B`,
  rule `#DDD8CB`.
- One accent: forest green `#1E4D3B` (soft tint `#E7EDE6`). Do not add a
  second accent colour.
- Headings: Newsreader (variable, self-hosted). Body: Instrument Sans
  (variable, self-hosted). No external CDNs.
- Dark bands (featured project, contact, footer) use ink `#1B2420` with
  sage text `#A9C2B2` / `#C9D8CD` (tints of the green, not a new accent).
- Display headings: large Newsreader (`.display`). The cover name is kept
  modest on purpose (owner finds a giant name conceited); one line.
- Light mode only. Borneo nod: the thin woven-diamond band (`.motif`) and the
  green; keep it quiet.
- Small uppercase letter-spaced labels in green or muted; hairline rules;
  generous whitespace; corners 2px, pills for chips only.
